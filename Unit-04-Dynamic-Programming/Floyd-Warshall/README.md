# Floyd-Warshall All-Pairs Shortest Paths

**Status:** Implementation pending.

## Problem and Algorithm
Compute shortest-path distances between every pair of vertices by allowing
intermediate vertices one at a time.

## Complexity

Time is `O(V^3)` and the distance matrix uses `O(V^2)` space. Explain how
infinity, negative edges, and negative cycles are represented or reported.

## Validation and Results
Test disconnected pairs, a direct shortest edge, negative edges without
negative cycles, and negative-cycle detection. Compare small graphs with a
trusted reference.

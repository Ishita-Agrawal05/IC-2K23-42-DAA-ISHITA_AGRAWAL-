# Fibonacci: Recursive Baseline

**Status:** Implementation pending.

## Problem and Algorithm
Compute the `n`th Fibonacci number using the direct recurrence with base cases
documented by the implementation.

## Complexity
The naive recursive recurrence takes exponential time, `O(phi^n)`, and
`O(n)` recursion-stack space.

## Validation and Results

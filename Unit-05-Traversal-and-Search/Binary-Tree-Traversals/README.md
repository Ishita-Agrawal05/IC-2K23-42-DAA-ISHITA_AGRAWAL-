# Binary Tree Traversals

**Status:** Implementation pending.

## Problem and Algorithm
Create a binary tree and implement preorder, inorder, and postorder traversal
recursively and iteratively. Define the tree input format.

## Complexity
Each traversal visits every node once: `O(n)` time. Auxiliary space is
`O(h)` for recursion or an explicit stack, where `h` is tree height.

## Validation and Results
Test empty, singleton, balanced, and skewed trees. Confirm iterative and
recursive traversals produce identical sequences.

# Unit 5: Traversal and Search

This unit covers tree traversal and graph search algorithms. The implementations in this folder demonstrate the basic representation and traversal methods used in graph and tree structures.

## Experiments

- [Binary Tree Traversals](Binary-Tree-Traversals/)
  - Preorder traversal
  - Inorder traversal
  - Postorder traversal

- [Graph Representation](Graph-Representation/)
  - Adjacency-list graph representation
  - Simple graph creation and display

- [BFS](BFS/)
  - Breadth-first search using a queue

- [DFS](DFS/)
  - Depth-first search using recursion

## Files included

- `binary_tree_traversals.py` — binary tree operations and traversal outputs
- `graph_representation.py` — graph creation and adjacency-list representation
- `bfs.py` — BFS traversal implementation
- `dfs.py` — DFS traversal implementation

## Objective

To understand how tree traversal and graph search algorithms work, how graphs are represented, and how traversal order differs depending on the chosen strategy.

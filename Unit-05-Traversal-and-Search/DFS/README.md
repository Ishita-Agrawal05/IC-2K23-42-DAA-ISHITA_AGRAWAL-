# Depth-First Search

**Status:** Implementation pending.

## Problem and Algorithm
Traverse a graph by exploring each branch before backtracking. Implement and
compare recursive and iterative variants; specify neighbor ordering.

## Complexity
With adjacency lists, time is `O(V + E)` and auxiliary space is `O(V)`.

## Validation and Results

graphs. Check visited-node coverage and compare recursive and iterative

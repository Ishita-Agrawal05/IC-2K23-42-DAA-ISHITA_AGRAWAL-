# Performance Measurement

## Status

Performance measurement is demonstrated by the existing [searching](../Searching/README.md)
and [sorting](../Sorting/README.md) experiments. The sorting comparison script
records timings to CSV and generates a graph.

## Method

Use increasing input sizes, reproducible input generation, repeated timings,
correctness checks, CSV output, and labeled plots. Keep timing separate from
input construction and output verification. Document the runtime environment
and discuss measured behavior against theoretical complexity.

## Results

The experiment-specific data and graphs remain with their corresponding
programs. A combined performance analyzer can be added here when it is
implemented.

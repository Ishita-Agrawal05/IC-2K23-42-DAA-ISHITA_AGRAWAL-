# Merge Sort

**Status:** Implementation pending in this unit. A merge-sort implementation
and performance results already exist in [Unit 1 Sorting](../../Unit-01-Introduction-to-Algorithms/Sorting/README.md).

## Algorithm and Complexity
Recursively sort two halves and merge them. Time is `O(n log n)` in best,
average, and worst cases; auxiliary storage is `O(n)`.
